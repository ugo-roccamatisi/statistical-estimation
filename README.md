# Introduction à l'estimation statistique — TP1 et TP2

Auteur : Ugo Roccamatisi.

- `tp1/tp1_Ugo_Roccamatisi.ipynb` : algorithme EM, mélange gaussien et sélection du nombre de composantes par BIC.
- `tp2/tp2_Ugo_Roccamatisi.ipynb` : histogrammes, estimation par noyaux 1D et 2D, génération d'images de chiffres.

Dans chaque dossier, `oldfaithful.npy` contient les données nécessaires. Ouvrir chaque notebook dans son dossier et exécuter les cellules de haut en bas. Les résultats et figures sont déjà enregistrés.

L'énoncé du TP1 contient une coquille dans la formule de la loi normale : l'exposant doit comporter un signe moins, comme dans l'implémentation.
